# OXO Game 🎮

A classic **Tic-Tac-Toe (OXO)** game built as a **Progressive Web App (PWA)** — playable in browser, installable on desktop & mobile, and works **offline**.

🔗 **[Play Live →](https://shamsanthosh123.github.io/oxo-game)**

---

## Features

- 👥 **2 Players** — local multiplayer on the same device
- 🤖 **vs Computer** — AI opponent with 3 difficulty levels
  - 🟢 Easy — random moves
  - 🟡 Medium — mixed strategy
  - 🔴 Hard — **Minimax + Alpha-Beta pruning** (unbeatable!)
- 🏆 **Scoreboard** — tracks wins, losses, draws across rounds
- ✨ **Win animation** — winning cells glow gold
- 📱 **PWA** — install it like a native app on any device
- ⚡ **Offline support** — works without internet after first visit

---

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | HTML5, CSS3, Vanilla JS |
| AI | Minimax Algorithm + Alpha-Beta Pruning |
| App | Progressive Web App (PWA) |
| Hosting | GitHub Pages |

## Run Locally

```bash
# Clone the repo
git clone https://github.com/YOUR_USERNAME/oxo-game.git
cd oxo-game

# Serve with Python
python -m http.server 3000

# Open in browser
# http://localhost:3000
```

---

## Install as App

1. Open the live link in **Chrome** or **Edge**
2. Click the **install icon** in the address bar (or browser menu → "Install OXO Game")
3. The game launches as a standalone app!
